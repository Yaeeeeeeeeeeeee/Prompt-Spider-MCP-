Optional Prompt Spider reporting (add only in projects that opt in):

When the reporter is installed and SPIDER_CLOUD_TOKEN and explicit SPIDER_ENDPOINT for the new Worker are configured, make a best-effort call at task start using `python /path/to/collectors/cloud/report.py task_started --run-file /tmp/spider-TASK-ID.run --project .`. Reuse that run file for heartbeat, waiting_confirmation, and the explicit final task_completed, task_failed, or task_cancelled event. Use a fresh run file for every independent task. Reporting failures must never prevent work. Never include prompt text, command output, paths, names, or credentials in reports. Run `python /path/to/collectors/cloud/report.py --flush` occasionally to retry queued events. This instruction is opt-in guidance, not a universal Codex lifecycle hook.
