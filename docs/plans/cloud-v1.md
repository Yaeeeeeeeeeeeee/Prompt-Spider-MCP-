## Shared wire contract (all contributors)
POST /api/events accepts legacy {event,project} OR V1 strict allowlist {version:1,event_id,source,project_id,run_id,event_type,status,timestamp,sequence?,node_id?,simulated?}. IDs bounded opaque [A-Za-z0-9_.:-], no names/full paths. source windows|cloud. status running|waiting|completed|failed|cancelled|stopped|ended|unknown. event_type explicit namespace scope: session_started/session_resumed/session_ended, prompt_submitted, waiting_confirmation, code_edit_started/code_edit_completed, command_started/command_completed, test_started/test_command_finished, model_request_completed/model_request_failed/model_request_cancelled, turn_stopped/turn_interrupted, task_started/task_completed/task_failed/task_cancelled, heartbeat. Only task_* terminal events may terminate a run as successful/failed/cancelled; session_end means ended; others never imply task success. timestamp ISO UTC RFC3339; server received_at separately. sequence nonnegative integer optional. Stable event_id reused on retry, unique event storage. payload contains no arbitrary strings other than bounded opaque IDs, enumerated event/status, timestamp. Legacy names retained in old table only, never interpolated into HTML.
POST ingest creds SPIDER_WINDOWS_TOKEN, SPIDER_CLOUD_TOKEN (enforced source) and legacy SPIDER_INGEST_TOKEN (legacy body only). Separate SPIDER_READ_TOKEN cannot equal any writer. Read APIs fail closed if creds absent or overlapping.
GET /api/runs => {runs:[{source,project_id,run_id,node_id,status,last_activity,events_count,simulated}],server_time}; GET /api/events?source=&project_id=&run_id=&limit= => {events:[V1 fields + received_at],server_time}; GET /api/legacy => protected legacy records. List APIs bounded, filters parameterized. Run identity (source,project_id,run_id). Missing heartbeat changes live run state to disconnected after 120s and timed_out after 900s; never auto-success. Out-of-order projection by sequence when consistently available; safe server receipt fallback, terminal task states cannot be undone by nonterminal/later delayed tool event. Session boundaries handled distinctly. More detail and tests owned by backend.
Dashboard same origin /, /app.js, /style.css assets static; user enters reader credential in password field only in memory; Authorization header, no browser persistent storage or URLs, no CORS. Dynamic content textContent. No demo data. Read errors explicit. Animation only licensed upstream if provenance verified, otherwise mark blocked and ship neutral status view.
